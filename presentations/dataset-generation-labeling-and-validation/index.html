Epic 105

Dataset Generation, Labeling, and Validation

Create an image-instruction-action dataset for supervised fine-tuning.

Intent | C4 context | Stories | ADR log

Epic Intent

Context: The paper relies on curated robotic demonstrations but does not provide a full dataset recipe, so the team must create a simplified version.

Scope: Data schema, simulation data collection, labels, train/validation split, dataset loader, quality checks, and dataset documentation.

Success criteria: Dataset schema is stable; first labeled dataset is created; loader works in training script; quality report identifies label issues.

This page is seeded from the Jira import CSV. Future agents should update it as implementation work starts, changes, or completes.
