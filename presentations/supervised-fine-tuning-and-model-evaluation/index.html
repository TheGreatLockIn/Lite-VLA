Epic 106

Supervised Fine-Tuning and Model Evaluation

Fine-tune a compact multimodal model to output robot actions.

Intent | C4 context | Stories | ADR log

Epic Intent

Context: The paper uses supervised image-to-action learning with LoRA before quantization; this epic implements a beginner-scaled version.

Scope: Training format, LoRA config, training loop, checkpoints, validation, manual inspection, and comparison against baseline.

Success criteria: First adapter trains successfully; validation metrics are reported; model outputs valid actions; results are reproducible from config.
