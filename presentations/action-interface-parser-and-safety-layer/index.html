Epic 103

Action Interface, Parser, and Safety Layer

Define safe structured actions and convert model text into bounded robot commands.

Intent | C4 context | Stories | ADR log

Epic Intent

Context: The model must produce deterministic action commands that are safe to parse and execute in ROS 2.

Scope: Discrete and continuous action schemas, parsers, validation, safety clamps, fallback STOP behavior, and command smoothing.

Success criteria: Invalid model output maps to STOP; velocity limits are enforced; parser has unit tests; action schema is documented.
