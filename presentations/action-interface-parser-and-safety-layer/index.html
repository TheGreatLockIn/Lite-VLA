Epic 103

Action Interface, Parser, and Safety Layer

Define safe structured actions and convert model text into bounded robot commands.

Intent | C4 context | Stories | ADR log

Epic Intent

Context: The model must produce deterministic action commands that are safe to parse and execute in ROS 2.

Scope: Discrete and continuous action schemas, parsers, validation, safety clamps, fallback STOP behavior, and command smoothing.

Success criteria: Invalid model output maps to STOP; velocity limits are enforced; parser has unit tests; action schema is documented.

Story 1017: Define discrete action schema

Intent
Create the first safe action vocabulary: five uppercase tokens with nominal velocity mapping for the MVP navigate-to-cube demo.
Implementation Walkthrough
  • litevla/actions/schema.py — DiscreteAction enum, ACTION_VELOCITIES, action_to_twist(), is_valid_action()
  • litevla/actions/__init__.py — public exports for downstream parser and ROS code
  • docs/action-schema.md + docs/html/action-schema.html — human and agent documentation with mapping table
  • scripts/run_dummy_pipeline.py — iterates ACTION_NAMES instead of ad-hoc FORWARD/STOP placeholders
  • tests/test_action_schema.py — enum order, mapping values, clamping, validation helpers
Data And Control Flow
flowchart LR
  Token["DiscreteAction token\nMOVE_FORWARD … STOP"]
  Map["ACTION_VELOCITIES\nnominal linear_x, angular_z"]
  Clamp["action_to_twist\nconfig safety limits"]
  Twist["Twist linear_x, angular_z"]
  Token --> Map --> Clamp --> Twist

Inputs: action token (enum or exact string). Outputs: clamped (linear_x, angular_z) using safety.max_linear_vel and safety.max_angular_vel from config. Parser (Story 1019) and safety layer (Story 1021) consume the same module.

ADR Notes

ADR: Five-token discrete vocabulary

Status: Accepted

Context: MVP non-goals defer continuous VLM velocity output; beginners need a small label set.

Decision: Standardize on MOVE_FORWARD, TURN_LEFT, TURN_RIGHT, SLOW_DOWN, STOP with nominal 0.2/0.1 m/s forward and ±0.6 rad/s turns.

Alternatives rejected: FORWARD alias (ambiguous); continuous JSON schema first (harder to train/parse for MVP).

Consequences: Dataset labels and prompts must use exact tokens; parser story validates strings before calling action_to_twist.

Validation
pytest tests/test_action_schema.py -q
python scripts/run_dummy_pipeline.py
