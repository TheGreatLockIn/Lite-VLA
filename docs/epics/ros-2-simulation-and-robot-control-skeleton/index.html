Epic 102

ROS 2 Simulation and Robot Control Skeleton

Build the non-ML robot loop that receives camera frames and publishes movement commands.

Intent | C4 context | Stories | ADR log

Epic Intent

Context: The paper routes model outputs through a ROS 2 bridge using velocity commands; this skeleton proves the robot path before adding ML.

Scope: Simulation environment, camera subscription, velocity publishing, dummy controller, heartbeat, and manual control.

Success criteria: Simulation runs; robot moves from dummy actions; camera frames are available; control loop remains stable without ML.
