ROS 2 Simulation and Robot Control Skeleton

Non-ML robot loop: Webots sim, camera ingress, bounded /cmd_vel, dummy and keyboard command sources, heartbeat safety.

Intent | Epic flow | Stories | ADR log

Epic Intent

Context: Model outputs must route through a ROS 2 bridge as velocity commands. This epic proves the robot path—simulation, perception ingress, actuation, and safety timing—before Epic 104/108 connect a VLA.

Scope: Simulator selection, Webots environment, camera subscriber, cmd_vel publisher, dummy action generator, heartbeat controller, manual teleop, command recording hooks for Epic 105 (VLA-42).

Success criteria: Webots runs on team laptops; robot moves from dummy and keyboard; /image_raw available; control loop stable without ML.

Status: Complete through VLA-28. Skeleton ready for Epic 108 model integration.

Contract: No node except the heartbeat path publishes /cmd_vel in normal operation. Action sources publish desired twists + discrete labels; heartbeat enforces rate, timeouts, and clamps.

Status: Accepted

Status: Accepted

Decision: run_teleop_sim.sh owns TTY + readiness gates instead of monolithic launch for keyboard input.
