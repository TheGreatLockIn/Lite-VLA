Epic 101 · VLA-19 / Story 1007

ROS 2 workspace setup

Repeatable colcon workspace and litevla_bridge package for the Lite-VLA robot control loop.

Intent

Every teammate can clone the repo, install ROS 2 Jazzy, run colcon build, source the overlay, and run a smoke node — without committing local build/ or install/ artifacts.

Layout

ros_ws/
├── README.md
├── scripts/build_ros_ws.sh
└── src/litevla_bridge/
    ├── package.xml
    ├── setup.py
    ├── config/bridge_params.yaml
    ├── litevla_bridge/workspace_ping.py
    └── test/

Build and run

source /opt/ros/jazzy/setup.bash
./ros_ws/scripts/build_ros_ws.sh
source ros_ws/install/setup.bash
ros2 run litevla_bridge workspace_ping

ADR: distribution and package name

Status: Accepted

Decision: ROS 2 Jazzy; package name litevla_bridge.

Consequences: Epic 102 nodes (camera, cmd_vel, dummy, heartbeat, teleop) ship inside this package.

Validation

cd ros_ws && ./scripts/build_ros_ws.sh && source install/setup.bash
colcon test --packages-select litevla_bridge
ros2 run litevla_bridge workspace_ping
