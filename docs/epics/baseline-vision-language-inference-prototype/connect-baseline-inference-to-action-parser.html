Connect baseline inference to action parser

Architectural walkthrough of InferenceAdapter — bridging VLM text output to Epic 103 parser and safety gate.

Summary · Mental model · Contract · Implementation · Verification · Learning

Executive summary

litevla.actions.InferenceAdapter calls InferenceWrapper.infer(), passes raw text through safe_command_from_text(), and returns clamped velocities with parse status and observability logs.

Evaluation and future ROS bridges should use this path so metrics match deployment safety behavior.

Mental model

Translator between probabilistic language and deterministic motion.

  • Beginner mistake: wiring wrapper output directly to /cmd_vel.
  • Senior watchpoint: double STOP paths; config limits; raw vs parsed logs.

API contract and data flow

image + instruction
  → InferenceWrapper.infer() → raw_text
  → safe_command_from_text() → SafeCommand
  → dict with safe_command, parse_status, timing
SurfaceRule
Configsafety.max_linear_vel, max_angular_vel
Parse failureSTOP velocities — no uncaught ValueError
successReflects inference, not semantic correctness

Implementation breakdown

infer_res = self.wrapper.infer(image, instruction, few_shot=few_shot)
safe_cmd = safe_command_from_text(
    infer_res["action"],
    max_linear_vel=self.max_linear_vel,
    max_angular_vel=self.max_angular_vel,
    logger=logger,
)

scripts/evaluate_baseline.py uses adapter.adapt_inference for predicted labels.

Engineering decisions

ADR: Model-to-action adapter — Accepted
Delegates parsing/clamping to safe_command_from_text; no inline ROS parsing.
