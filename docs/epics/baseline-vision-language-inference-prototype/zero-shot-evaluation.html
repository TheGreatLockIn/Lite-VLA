Zero-shot baseline evaluation

Benchmark pipeline for unfine-tuned SmolVLM — 20-image augmented set, syntax vs semantic metrics, and latency splits in results.json.

Summary · Mental model · Contract · Implementation · Verification · Learning

Executive summary

Zero-shot evaluation measures how well unfine-tuned SmolVLM follows discrete prompts on a fixed 20-image set. generate_test_set.py builds augmentations; evaluate_baseline.py runs InferenceAdapter and writes benchmark JSON.

Separate valid action rate (syntax) from correct action rate (semantics) before investing in dataset collection or LoRA.

Mental model

Regression exam for the VLA stack — not a safety certificate.

  • Beginner mistake: celebrating 100% valid rate with poor semantic accuracy.
  • Senior watchpoint: dummy vs model mode; adapter vs raw strings; failure categories A/B/C.

API contract and data flow

generate_test_set.py → metadata.json + images/
evaluate_baseline.py → adapter per record → results.json
