Baseline inference wrapper

Architectural walkthrough of litevla.inference.InferenceWrapper — SmolVLM loading, greedy decoding, timings, and fail-safe STOP fallback.

Summary · Mental model · Contract · Implementation · Verification · Learning

Executive summary

InferenceWrapper is the callable VLA boundary: preprocess → prompt → model.generate → decoded text plus per-stage timings. Returns raw text, not safe velocities.

runtime.mode: dummy runs without weights for CI; model loads AutoModelForImageTextToText for SmolVLM.

Mental model

Black-box "what should we do?" API for vision + language.

  • Tension: greedy decoding for determinism vs sampling for diversity.
  • Beginner mistake: treating returned string as a validated command.
  • Senior watchpoint: device/dtype, few-shot order, exception → STOP.

API contract and data flow

BGR + instruction
  → ImagePreprocessor → PIL
  → PromptFormatter → prompt (+ few-shot images)
  → processor + generate(do_sample=False)
  → action str + timing dict
SurfaceRule
Outputaction, timing, success, error
FailureAny exception → action: STOP, success: False
InvariantNever raises on model failure
