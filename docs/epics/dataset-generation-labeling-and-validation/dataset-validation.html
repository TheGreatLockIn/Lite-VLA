Dataset validation checks

Automated quality gate: schema validation, image path checks, duplicate ids, and label distribution reports with JSON output.

Summary · Contract · Implementation · Decisions · Verification · Related

Executive summary

VLA-45 owns the automated quality gate on processed JSONL before fine-tuning and after human review (VLA-44). Unlike read_jsonl() which fails on the first bad row, validate_dataset() scans the entire file, collects every schema/filesystem problem with line numbers, and emits action/source distribution summaries with imbalance warnings.

API contract and data flow

train.jsonl ──> validate_dataset()
                  ├── per-line JSON + parse_training_record()
                  ├── image exists under repo_root  [optional]
                  ├── duplicate id tracking
                  └── action/source counters
              ──> DatasetValidationReport ──> validation_report.json

Implementation breakdown

Core API (litevla/data/validator.py)

report = validate_dataset(
    "data/processed/v0.1.0/train.jsonl",
    check_images=True,
    warn_on_imbalance=True,
)
assert report.valid  # error_count == 0
  • Design note: valid ignores warnings — imbalance does not block release.
  • Gotcha: CI on fixtures uses check_images=False because PNGs are gitignored.

CLI (scripts/validate_dataset.py)

python scripts/validate_dataset.py --jsonl data/processed/v0.1.0/train.jsonl
python scripts/validate_dataset.py --jsonl data/fixtures/sample_train.jsonl --skip-image-check
python scripts/validate_dataset.py --version v0.1.0 --write-artifacts

Engineering decisions

ADR: Collect-all-errors validator (10099)

Status: Accepted
Decision: Aggregate all row errors into DatasetValidationReport instead of failing on first bad line.

ADR: Image check optional (10100)

Status: Accepted
Decision: check_images flag; default on for release, off for schema-only CI.

ADR: Imbalance as warning (10101)

Status: Accepted
Decision: action_imbalance at 50% threshold is warning only.

Verification patterns

pytest tests/test_dataset_validator.py -q
python scripts/validate_dataset.py --jsonl data/fixtures/sample_train.jsonl --skip-image-check

Defends: schema errors, missing images, duplicate ids, distribution warnings, JSON report write.
