Epic 105 · Jira VLA-6

Dataset Generation, Labeling, and Validation

Image-instruction-action dataset for supervised fine-tuning: schema, raw capture, processed JSONL, validation, loader.

Intent | Epic flow | Stories | ADR log

Epic Intent

Context: LiteVLA-Edge assumes curated demonstrations; the team must define how examples are captured, stored, validated, and loaded for fine-tuning on beginner-friendly hardware.

Scope: Training record schema, simulation capture, starter dataset builder, labeling workflow, validator, PyTorch loader, versioning docs.

Success criteria: Stable schema; ≥200 labeled examples; loader runs in training script; quality report catches bad rows.

Status: Complete through VLA-47. Epic 105 ready for Epic 106 fine-tuning integration.

Epic ADR Log

Two-layer JSONL (VLA-41)

Status: Accepted

Decision: Raw capture shape ≠ training shape; builder is mandatory gate.

Sim-time join (VLA-42 → VLA-43)

Status: Accepted

Decision: Shared sim_stamp_sec/nanosec; forward-fill labels per frame.

Augment to 200 rows (VLA-43)

Status: Accepted

Decision: Pillow variants on reference PNGs until teleop volume is sufficient.

CSV review round-trip (VLA-44)

Status: Accepted

Decision: Export JSONL to CSV for spreadsheet review; import validates and sets manual_review provenance.

Validator before training (VLA-45)

Status: Accepted

Decision: Non-throwing validate_dataset collects all issues; CI uses --skip-image-check on fixtures-only checkouts.
