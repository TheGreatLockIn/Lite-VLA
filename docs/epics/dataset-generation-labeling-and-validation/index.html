Dataset Generation, Labeling, and Validation

Image-instruction-action dataset for supervised fine-tuning: schema, raw capture, processed JSONL, validation, loader.

Intent | Epic flow | Stories | ADR log

Epic Intent

Context: LiteVLA-Edge assumes curated demonstrations; the team must define how examples are captured, stored, validated, and loaded for fine-tuning on beginner-friendly hardware.

Scope: Training record schema, simulation capture, starter dataset builder, labeling workflow, validator, PyTorch loader, versioning docs.

Success criteria: Stable schema; ≥200 labeled examples; loader runs in training script; quality report catches bad rows.

Status: Code complete for VLA-41–47. Processed release v0.1.0 built locally (200 rows, balanced across four Epic 103 actions). Epic 105 API is ready for Epic 106; teleop raw capture and VLM training transforms remain external.

Story 1033: Implement dataset validation checks

VLA-45 — task doc (10099 · 10100 · 10101)

Intent
Automated quality gate on processed JSONL: collect-all-errors schema scan, optional image existence checks, duplicate-id detection, and action/source distribution with imbalance warnings.
Implementation Walkthrough
  • litevla/data/validator.py — validate_dataset, DatasetValidationReport, issue codes (schema_invalid, missing_image, action_imbalance, …)
  • scripts/validate_dataset.py — CLI with --skip-image-check and --write-artifacts
  • resolve_image_path() — shared repo-relative PNG resolution (same rule as VLA-46 loader)
Data And Control Flow
JSONL → per-line parse_training_record() → optional filesystem image check → aggregated DatasetValidationReport → stdout summary or validation_report.json (VLA-47).
ADR Notes
Collect-all-errors: Unlike read_jsonl(), validator returns every row error for QA. Imbalance as warning: >50% single-action share warns but does not block report.valid.
Verification Patterns

python scripts/validate_dataset.py --jsonl data/processed/v0.1.0/train_reviewed.jsonl --review-csv data/processed/v0.1.0/label_review.csv

Story 1034: Create dataset loader for training

Epic ADR Log

Two-layer JSONL (VLA-41)

Status: Accepted

Decision: Raw capture shape ≠ training shape; builder is mandatory gate.

Sim-time join (VLA-42 → VLA-43)

Status: Accepted

Decision: Shared sim_stamp_sec/nanosec; forward-fill labels per frame.

Augment to 200 rows (VLA-43)

Status: Accepted (updated 2026-07-02)

Decision: Pillow variants on reference PNGs until teleop volume is sufficient; cap single-image dominance (25 variants when only one reference exists); scale per-image variants when multiple reference poses are present.

CSV review round-trip (VLA-44)

Status: Accepted

Decision: Export JSONL to CSV for spreadsheet review; import validates and sets manual_review provenance.

Validator before training (VLA-45)

Status: Accepted

Decision: Non-throwing validate_dataset collects all issues; CI uses --skip-image-check on fixtures-only checkouts.

Transform hook loader (VLA-46)

Status: Accepted

Decision: LiteVLADataset returns PIL + dict; Epic 106 training script supplies VLM-specific transform and collator.

Versioned processed releases (VLA-47)

Status: Accepted

Decision: vMAJOR.MINOR.PATCH folders with VLA-45 reports and generated DATASET_CARD.md; config points training at one version id.

One-command release (VLA-43–47)

Status: Accepted

Decision: scripts/run_dataset_release.sh chains build → review export → bulk-approve → import → validate with pending gate → version artifacts → loader smoke.
