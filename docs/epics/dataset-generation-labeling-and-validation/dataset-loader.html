Dataset loader for training

LiteVLADataset — PyTorch Dataset over processed JSONL with optional image transforms for Epic 106 fine-tuning.

Summary · Contract · Implementation · Decisions · Verification · Related

Executive summary

VLA-46 bridges processed JSONL (VLA-41) into Epic 106 fine-tuning. LiteVLADataset loads repo-relative RGB images with Pillow, returns instruction + Epic 103 action labels, and accepts an optional transform for torchvision/VLM preprocessing. Model-specific normalization stays in the training script, not the loader.
