Dataset loader for training

LiteVLADataset — PyTorch Dataset over processed JSONL with optional image transforms.

Executive summary

Loads validated JSONL rows, opens repo-relative RGB images, returns dicts for DataLoader batching into Epic 106 fine-tuning.

Usage

from litevla.data.loader import LiteVLADataset

dataset = LiteVLADataset("data/processed/v0.1.0/train.jsonl")
sample = dataset[0]  # image, instruction, action, ...
