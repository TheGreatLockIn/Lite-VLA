# Dataset versioning and documentation

**Epic:** Dataset Generation, Labeling, and Validation (105) · **Jira epic:** VLA-6 · **Story:** VLA-47 / 1035 · **Subtasks:** 10105 (naming), 10106 (stats), 10107 (dataset card)

**Human-readable version (browser):** [`dataset-versioning.html`](dataset-versioning.html)

## Executive summary

VLA-47 defines the **processed dataset release layout**: version directories `data/processed/vMAJOR.MINOR.PATCH/`, auto-generated `validation_report.json`, optional `validation_report_val.json`, and `DATASET_CARD.md` summarizing scope, label mix, and validation status.

## API contract and data flow

```text
data/processed/v0.1.0/
├── train.jsonl
├── val.jsonl
├── images/                  # augmentations (gitignored)
├── validation_report.json   # VLA-45 stats (10106)
├── validation_report_val.json
└── DATASET_CARD.md          # human summary (10107)
```

| Convention | Rule |
|------------|------|
| Version id | `v\d+\.\d+\.\d+` (e.g. `v0.1.0`) |
| Stats file | `validation_report.json` from `DatasetValidationReport.to_dict()` |
| Card | Markdown generated by `render_dataset_card()` |

## Implementation breakdown

### `litevla/data/versioning.py`

- **`build_version_artifacts`** — validate train (+ val if present), write stats + card
- **`write_dataset_stats`** / **`write_dataset_card`** — individual writers

### CLI integration

```bash
# After build
python scripts/build_starter_dataset.py --write-artifacts

# Or standalone
python scripts/validate_dataset.py --version v0.1.0 --write-artifacts
```
