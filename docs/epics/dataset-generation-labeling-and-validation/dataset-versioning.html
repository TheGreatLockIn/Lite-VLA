Dataset versioning and documentation

Processed releases under data/processed/vMAJOR.MINOR.PATCH/ with validation_report.json and DATASET_CARD.md.

Summary · Contract · Implementation · Decisions · Verification · Related

Executive summary

VLA-47 packages a processed dataset release: validated JSONL splits, optional augmented images, machine-readable validation_report.json (VLA-45), and human-readable DATASET_CARD.md. Version strings are validated before paths are constructed.

API contract and data flow

build_version_artifacts(version="v0.1.0", train_jsonl=..., val_jsonl=...)
        │
        ├── validation_report.json      (train stats)
        ├── validation_report_val.json  (if val present)
        └── DATASET_CARD.md             (human summary)
ConventionRule
Version idv\d+\.\d+\.\d+ e.g. v0.1.0
StatsDatasetValidationReport.to_dict()
Cardrender_dataset_card() markdown
Configconfigs/default.example.yaml → data.processed_version

Engineering decisions

Status: Accepted

ADR: Stats from validator (10106)

Status: Accepted
Decision: Reports are VLA-45 output, not ad-hoc builder counters.

ADR: Generated dataset card (10107)

Status: Accepted
Decision: DATASET_CARD.md rendered from live validation reports.
