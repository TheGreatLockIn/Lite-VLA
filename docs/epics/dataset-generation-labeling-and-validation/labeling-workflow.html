Labeling workflow

Human review via CSV export/import: guidelines, template, checklist, and scripts/label_review.py round-trip into validated JSONL.

Summary · Contract · Guidelines · Checklist · Implementation · Verification · Open questions · Related

Executive summary

VLA-44 owns the human review path between VLA-43 processed JSONL and training-ready data. Reviewers work in a spreadsheet-friendly CSV (data/templates/label_review.csv), not in JSONL directly. Export → edit → import preserves traceability via id, review_status, and metadata.review on merged rows. Approved and corrected rows become source: manual_review; rejected rows are dropped from the import output.

API contract and data flow

processed/v0.1.0/train.jsonl
        │
        ▼
  label_review.py export  ──>  label_review.csv  (spreadsheet)
        │
        ▼  human sets review_status, action_reviewed, reviewer, notes
        │
  label_review.py import  ──>  train_reviewed.jsonl
ContractRule
Review formatCSV with fixed columns
Training formatJSONL only — CSV never enters training directly
review_statuspending | approved | corrected | rejected
Final actioncorrected → action_reviewed; else proposed or reviewed
Traceabilitymetadata.review stores reviewer, notes, original action/source

Labeling guidelines (10096)

Answer: “What should the robot do next?” given the image and instruction.

ActionWhen to use
MOVE_FORWARDClear path toward target; target visible ahead
TURN_LEFT / TURN_RIGHTTarget off-center or not visible
SLOW_DOWNApproaching target cautiously
STOPGoal reached, blocked, or halt required

Do not use: teleop-only tokens (MOVE_BACKWARD, combos), or synonyms (FORWARD, GO).

Review checklist (10098)

Printable checklist: label_review_checklist.md

  • corrected rows have valid action_reviewed
  • Rejected rows document review_notes
  • Spot-check after import

Implementation breakdown

Template

data/templates/label_review.csv — column headers + two example rows.

CLI

python scripts/label_review.py export \
  --jsonl data/processed/v0.1.0/train.jsonl \
  --output data/processed/v0.1.0/label_review.csv

python scripts/label_review.py import \
  --jsonl data/processed/v0.1.0/train.jsonl \
  --csv data/processed/v0.1.0/label_review.csv \
  --output data/processed/v0.1.0/train_reviewed.jsonl

Python API

litevla/data/label_review.py — export_jsonl_to_review_csv, import_review_csv_to_jsonl.

Engineering decisions

ADR: CSV for review, JSONL for training (10097) — Accepted. Spreadsheet UX for humans; validated JSONL for training.

ADR: Reject drops row on import (10098) — Accepted. Rejected examples never reach training output.

Verification patterns

pytest tests/test_label_review.py -q
