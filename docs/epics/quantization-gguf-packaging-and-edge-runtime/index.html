Epic 107

Quantization, GGUF Packaging, and Edge Runtime

Compress and package the trained model for faster local inference.

Intent | C4 context | Stories | ADR log

Epic Intent

Context: The paper uses post-training 4-bit GGUF quantization and llama.cpp CUDA inference for on-device deployment.

Scope: Quantization experiments, GGUF conversion research, llama.cpp execution, Jetson setup, runtime configuration, and FP32 versus quantized comparison.

Success criteria: Quantized inference path is documented; at least one low-bit model runs; latency is measured; export blockers are explicitly captured.
