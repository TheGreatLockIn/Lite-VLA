Story 1036: Prepare model training format

Intent
Convert labeled examples into the model-specific supervised fine-tuning format. Deliverable: prepare-model-training-format.html
Implementation Walkthrough
Created the SFTDataFormatter class in litevla/training/formatter.py. It converts visual frames, goal commands, and target actions into standard Hugging Face conversation dictionaries, tokenizes them using the VLM processor, and constructs a training labels mask by replacing all prompt tokens with -100. We registered SFTDataFormatter in litevla/training/__init__.py.
Data And Control Flow
Inputs: Image array/PIL object + goal instruction + correct action string.
Outputs: A dictionary containing tokenized input_ids, masked target labels, and image features (pixel_values).
Flow: Demonstration Logs ➔ Conversation Formatting ➔ Tokenizer/Processor ➔ Masking (first N tokens set to -100) ➔ Training Batch payload.
ADR Notes
ADR: Unified Multimodal Token Length Alignment
Status: Accepted
Context: Prompt tokenization offsets must match the full sequence tokens exactly. Tokenizing text without image tags causes alignment mismatch due to dynamic visual placeholder expansion.
Decision: Tokenize both the prompt prefix and the full conversation using the same image matrix.
Validation
Created unit tests in tests/test_training_formatter.py verifying conversation building, numpy/PIL image standardization, and token masking. Verified that all tests execute and pass successfully:
pytest tests/test_training_formatter.py -v
pytest
