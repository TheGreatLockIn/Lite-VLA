How To Use These Pages

Each epic has one HTML walkthrough page that grows as teammates complete stories and subtasks. Completed stories may also have paired task docs (<task-slug>.md + .html) in the same epic folder. Agents should update the relevant page while doing implementation work so the team can later explain the code, architecture, data flow, and decisions without reconstructing history from commits.

The pages use task-level Mermaid flowcharts or sequence diagrams for implementation details, focused code snippets for walkthroughs, and short ADR entries for technical decisions.
