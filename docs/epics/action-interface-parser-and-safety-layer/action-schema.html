Epic 103 · VLA-29 / Story 1017

Discrete action schema

The five allowed VLA output tokens, how each maps to bounded ROS velocities, and a walkthrough of the shared litevla.actions module.

Purpose · Reader map · Actions · Code · Flow · Engineering · Validation

Purpose and fit

Story 1017 defines the first shared contract between the VLA model and robot control. The model outputs one of five uppercase discrete tokens; this story implements the vocabulary and velocity mapping in litevla.actions so parsers, datasets, prompts, and ROS code stay aligned.

In the epic pipeline, this story sits before the parser (Story 1019) and the dedicated safety gate (Story 1021). It answers: given a valid token, what bounded (linear_x, angular_z) should we request?

Allowed actions

Action Meaning Nominal linear_x (m/s) Nominal angular_z (rad/s)
MOVE_FORWARD Drive toward the goal 0.2 0.0
TURN_LEFT Rotate left in place 0.0 0.6
TURN_RIGHT Rotate right in place 0.0 −0.6
SLOW_DOWN Reduce forward speed near target 0.1 0.0
STOP Halt immediately 0.0 0.0

Names are uppercase and underscore-separated. Aliases like FORWARD are intentionally rejected.

Code walkthrough

litevla/actions/schema.py

Design-point constants (DEFAULT_LINEAR_FORWARD, DEFAULT_LINEAR_SLOW, DEFAULT_ANGULAR_TURN) mirror MVP speeds from the requirements doc so tests and implementation share one source of truth.

DiscreteAction is a str enum: each member’s value is the exact token the model must emit. ACTION_NAMES exposes stable iteration order for scripts and tests. ACTION_VELOCITIES maps each action to nominal (linear_x, angular_z) before config clamping.

is_valid_action(name) returns whether a string is an exact enum value — the parser story will use this class of check before mapping. clamp_velocity clamps a scalar to [-limit, limit]. action_to_twist(...) looks up nominal velocities, clamps with config limits, and returns floats for ROS Twist. Invalid strings raise ValueError; safe fallback to STOP is deferred to Story 1021.

Supporting files

  • litevla/actions/__init__.py — re-exports the public API; import litevla.actions in app code.
  • scripts/run_dummy_pipeline.py — loads config, iterates ACTION_NAMES, prints clamped velocities.
  • tests/test_action_schema.py — naming rules, mappings, clamping, validation, and error cases.
from litevla.actions import DiscreteAction, action_to_twist

linear, angular = action_to_twist(
    DiscreteAction.MOVE_FORWARD,
    max_linear_vel=0.2,
    max_angular_vel=0.6,
)
# (0.2, 0.0)

Engineering notes

  • Discrete first — easier labeling, evaluation, and deterministic parsing than continuous VLM velocities.
  • Nominal + clamp — motion meaning stays in ACTION_VELOCITIES; deployment limits stay in config.
  • No aliases — strict tokens keep parser tests and dataset QA simple.
  • Story 1021 will add invalid-output STOP fallback and ROS-side enforcement beyond this module’s clamping.

ADR: Five-token discrete vocabulary

Status: Accepted

Decision: Standardize on five uppercase tokens with nominal 0.2/0.1 m/s forward and ±0.6 rad/s turns.

Alternatives rejected: FORWARD alias; JSON velocity schema as the primary MVP path.
