Epic 103 · Story 1021

Safety clamp and fallback behavior

Fail-safe boundary between VLA model text and bounded /cmd_vel publishing.

Summary · Contract · Learning · Implementation · Decisions · Verification

Executive summary

litevla.actions.safety is the fail-safe boundary between VLA model text and ROS /cmd_vel publishing. It composes the discrete parser (Story 1019) and velocity mapper (Story 1017), clamps every command to configured limits, converts parse failures into zero-velocity STOP, and logs safety events with the original model output.

Subtasks covered: 10063 (velocity clamp), 10064 (invalid-output STOP), 10065 (safety event logging), 10252 and 10253 (learning).

Learning notes

Subtask 10252 — Velocity clamping and operational limits

Why clamp? Nominal discrete speeds or future continuous outputs must never exceed deployment ceilings.

  • Per-axis clamping — clamp_velocity maps each axis into [-limit, limit].
  • Nominal vs. config limits — ACTION_VELOCITIES is stable for training; config tightens deploy limits.
  • Detection — VELOCITY_CLAMPED events when nominal values exceed config (RSK-04).

MVP limits: linear ≤ 0.2 m/s, angular ≤ 0.6 rad/s at full design point.

Subtask 10253 — Fail-safe fallback and safety event logging

Why fallback STOP? VLMs can emit conversational text instead of action tokens (RSK-02).

  • Fail-report vs. fail-safe — parser returns None; safety gate publishes STOP.
  • Safety events — SafetyEventKind: ok, parse_failure, velocity_clamped.
  • Logging levels — WARNING for failures/clamps with original text; DEBUG for OK.

ROS nodes should call safe_command_from_text before publishing Twist.

Implementation breakdown

Velocity clamp (Subtask 10063)

def clamp_twist_velocities(
    linear_x: float,
    angular_z: float,
    *,
    max_linear_vel: float,
    max_angular_vel: float,
) -> tuple[float, float, bool]:
    clamped_linear = clamp_velocity(linear_x, max_linear_vel)
    clamped_angular = clamp_velocity(angular_z, max_angular_vel)
    was_clamped = clamped_linear != linear_x or clamped_angular != angular_z
    return clamped_linear, clamped_angular, was_clamped

Design: Reuses Story 1017 clamp_velocity. Standalone helper for future JSON/continuous paths.

Invalid-output STOP (Subtask 10064)

parsed = parse_discrete_action(text)
if parsed is None:
    return SafeCommand(
        linear_x=0.0,
        angular_z=0.0,
        action=DiscreteAction.STOP,
        original_text=text,
        events=(SafetyEvent(kind=SafetyEventKind.PARSE_FAILURE, ...),),
    )

Design: Never raises. Every path returns a bounded SafeCommand.

Safety event logging (Subtask 10065)

def _log_event(event: SafetyEvent, *, logger: logging.Logger) -> None:
    if event.kind is SafetyEventKind.OK:
        logger.debug(event.message)
        return
    detail = f"{event.message} (original_text={event.original_text!r})"
    logger.warning(detail)

Design: Structured SafeCommand.events for tests; logging for live nodes.

Engineering decisions

ADR: Central safety gate for discrete MVP
Status: Accepted
Context: Parser reports failure; schema fail-fast; ROS needs fail-safe publishing (RSK-02, RSK-04).
Decision: safe_command_from_text / safe_command_from_action in litevla.actions.safety.
Alternatives Rejected: STOP inside parser; try/except at every call site.
Consequences: Route all model text through the safety gate before /cmd_vel.
