Mentorship Curriculum

Deep-dive guides designed to teach the inner workings of our codebase step-by-step.

About This Curriculum

This folder contains detailed code guides designed for learning and onboarding. Unlike traditional reference docs, these guides focus on data lifecycles, naive vs. chosen engineering decisions, and active diagnostic exercises to ensure you can confidently extend and modify the system.

Curriculum Modules (VLA-06 Dataset Generation)

Module 1: Schemas and Episode Layouts

Files covered: litevla/data/schema.py, litevla/data/episode.py

Understand how raw episode captures and training records are structured in memory using Python dataclasses, and validated against JSON Schemas.

Module 2: Dataset Building and Validation

Files covered: litevla/data/builder.py, litevla/data/validator.py

Learn how raw simulation steps are converted into aligned training pairs, augmented for visual variety, split into train/val partitions, and validated for dataset integrity.

Module 3: PyTorch Dataset Loader

Files covered: litevla/data/loader.py

Dive into how the dataset loader transforms raw directory strings and PNG frames into standard PyTorch batches ready for training loops.
