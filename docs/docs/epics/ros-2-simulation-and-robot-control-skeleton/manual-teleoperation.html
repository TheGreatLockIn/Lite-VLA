Manual teleoperation mode

Keyboard teleop with command recording for dataset work.

Run

./ros_ws/scripts/run_teleop_sim.sh

Requires an interactive terminal (TTY) for keyboard input. The wrapper starts Webots, heartbeat, and command recording in the background, then keeps teleop_keyboard in the foreground so w/a/d reach the node.
