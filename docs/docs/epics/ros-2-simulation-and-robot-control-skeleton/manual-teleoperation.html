Epic 102 · VLA-28

Manual teleoperation mode

Keyboard teleop with command recording for dataset work.

Run

source /opt/ros/jazzy/setup.bash
source ros_ws/install/setup.bash
./ros_ws/scripts/run_teleop_sim.sh

Requires an interactive terminal (TTY). The script stops stale processes, launches Webots in interactive mode, waits for /clock and active diff-drive controllers, then starts heartbeat + recorder and keeps teleop_keyboard in the foreground.

./ros_ws/scripts/stop_teleop_sim.sh

Use stop_teleop_sim.sh before restarting if a previous session left Webots or ROS nodes running.

Key map (game-style)

KeyAction
w / ↑Drive forward
s / ↓Drive backward
a / ←Turn left
d / →Turn right
x / spaceBrake
qQuit

Hold keys to drive; release to stop within ~120 ms. Combine w+a to arc turn. ML SLOW_DOWN remains model-only; teleop s is full reverse.
