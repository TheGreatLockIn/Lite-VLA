Low-level control heartbeat

Steady /cmd_vel at heartbeat_hz with safety timeouts.

Run

ros2 launch litevla_bridge dummy_sim.launch.py
ros2 topic hz /cmd_vel
ros2 topic echo /litevla/diagnostics --once

Modules

  • heartbeat_controller.py — ROS node that owns /cmd_vel publishing, listens to desired twists and frames, and manages timeouts
  • heartbeat_utils.py — Pure python helpers for timeout logic and diagnostics assembly

Validation

colcon test --packages-select litevla_bridge
