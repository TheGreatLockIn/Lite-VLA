ROS 2 Simulation and Robot Control Skeleton

Build the non-ML robot loop that receives camera frames and publishes movement commands.

Intent | Epic flow | Stories | ADR log

Epic Intent

Context: Model outputs route through a ROS 2 bridge as velocity commands; this skeleton proves the robot path before ML.

Scope: Simulation environment, camera subscription, velocity publishing, dummy controller, heartbeat safety layer, manual teleop.

Success criteria: Simulation runs; robot moves from dummy and keyboard commands; camera frames available; control loop stable without ML.

Status: Complete through VLA-28 — skeleton ready for Epic 108 model integration.

Story 1016: Add manual teleoperation mode

VLA-28 — task doc

Intent
Keyboard override for testing and dataset capture; integrates with heartbeat and JSONL recorder.
Implementation Walkthrough
  • teleop_utils.py — game-style holds, key combos, MOVE_BACKWARD label
  • teleop_keyboard.py — TTY cbreak, 50 Hz poll → /litevla/desired_twist
  • run_teleop_sim.sh / stop_teleop_sim.sh — canonical lifecycle (not launch stdin)
  • InteractiveWebotsLauncher — GUI camera for teleop
  • command_recorder.py — outputs/teleop/*.jsonl
ADR Notes

Shell script owns stdin: ros2 launch teleop_sim.launch.py is not valid for keyboard driving.

Teleop tuning: 25 Hz heartbeat, 200 ms action timeout, require_frame:=false, 20 s startup grace.

Verification Patterns
./ros_ws/scripts/run_teleop_sim.sh
./ros_ws/scripts/stop_teleop_sim.sh
colcon test --packages-select litevla_bridge
Open Questions
