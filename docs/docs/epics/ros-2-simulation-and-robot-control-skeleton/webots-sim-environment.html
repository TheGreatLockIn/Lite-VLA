Epic 102 · VLA-23

Webots simulation environment

GPU-friendly MVP: mvp_arena.wbt, litevla_robot, /image_raw, /cmd_vel.

Two-part install

Installing ros-jazzy-webots-ros2 alone is not enough. You also need the Webots simulator application.

Step Component Command
1 ROS 2 bridge sudo apt install ros-jazzy-webots-ros2
2 Webots app ./ros_ws/scripts/install_webots.sh

Verify: ./ros_ws/scripts/find_webots.sh

Run

source /opt/ros/jazzy/setup.bash
./ros_ws/scripts/build_ros_ws.sh
source ros_ws/install/setup.bash
./ros_ws/scripts/run_webots_mvp.sh

Verify spawn (VLA-117)

ros2 launch litevla_bridge verify_spawn.launch.py

Troubleshooting

“Webots not found in PATH” — run install_webots.sh (step 2). The ROS bridge apt package does not include the simulator.

Why Webots (not Isaac)

Isaac Sim exceeded team GPU/VRAM. Webots matches original MVP docs and runs lighter alongside VLA inference.
