Epic 101

Repository, Development Environment, and Tooling

Create a stable engineering foundation for Python, ROS 2, ML experiments, and deployment scripts.

Intent | C4 context | Stories | ADR log

Epic Intent

Context: The team needs a repeatable setup before building the model, ROS nodes, and benchmarks.

Scope: Repo layout, dependency management, local dev setup, coding standards, CI basics, configuration, and run scripts.

Success criteria: A new engineer can run setup from README; workspace builds locally; basic checks run in CI; configuration is versioned safely.

Story 1007: Create ROS 2 workspace setup

Task doc (VLA-19)

Intent
Make ROS workspace creation repeatable for all teammates (Jira VLA-19).
Implementation Walkthrough
  • ros_ws/README.md — layout, prerequisites, build, test, and sourcing commands
  • ros_ws/scripts/build_ros_ws.sh — sources /opt/ros/jazzy/setup.bash and runs colcon build --symlink-install
  • ros_ws/src/litevla_bridge/ — ament_python control bridge package (camera, cmd_vel, dummy, teleop nodes land here in Epic 102)
  • litevla_bridge/workspace_ping.py — smoke executable registered as ros2 run litevla_bridge workspace_ping
  • config/bridge_params.yaml — starter ROS params (heartbeat placeholder)
Data And Control Flow
flowchart LR
  Dev[Developer] --> Build[build_ros_ws.sh]
  Build --> Colcon[colcon build]
  Colcon --> Install[install/setup.bash]
  Install --> Ping[workspace_ping node]
  Ping --> Log[ROS log: package OK]
No robot topics yet — this story only establishes the buildable workspace overlay.
ADR Notes

ADR: ROS 2 Jazzy + litevla_bridge package — Status: Accepted.

Context: one distro and one bridge package for the non-ML robot loop.

Decision: Jazzy on Ubuntu 24.04; package name litevla_bridge.

Alternatives rejected: per-node packages (too heavy for MVP); ROS Humble (project docs target Jazzy).

Validation
source /opt/ros/jazzy/setup.bash
./ros_ws/scripts/build_ros_ws.sh
source ros_ws/install/setup.bash
colcon test --packages-select litevla_bridge
ros2 run litevla_bridge workspace_ping
